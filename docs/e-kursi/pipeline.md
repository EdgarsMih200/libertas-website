# E-kursi — пайплайн разработки курса · этап 3

Статус: **на согласовании**. После «да» → скилл `/e-kurss`, который выполняет этот пайплайн.

## Принципы экономии токенов

1. **Всё детерминированное делают скрипты, а не Claude**: извлечение текста, проверка, сборка экзамена, повторения, загрузка.
2. **Claude читает текст, а не картинки.** PDF → `pdftotext` (0 токенов). Страницы-картинки без текста скрипт перечисляет;
   Claude смотрит только их и в низком разрешении.
3. **Один урок = один контекст.** На входе только план урока, сжатый текст этого урока и схема. Остальные уроки не читаются.
4. **Сначала дешёвый план, потом дорогая генерация.** Ошибки в плане исправляются до написания уроков.
5. **Контент = компактный JSON по схеме**, HTML рисует один общий плеер. Короткие ключи, без разметки.
6. **Правки точечные**: по `id` задания через Edit, урок целиком не перегенерируется.
7. **Скилл хранит схему и правила**: их не нужно объяснять заново в каждой сессии.

Оценка для курса из 5 уроков: ≈ 150–200 тыс. токенов на весь курс (план ≈ 25 тыс., урок ≈ 20–30 тыс., экзамен с ресурсами ≈ 15 тыс.).

## Где лежит контент (важно: репозиторий публичный)

| Что | Где | В git? |
|---|---|---|
| Плеер, API, схема, скрипты | `libertas-website` (публичный) | да |
| Исходники (PDF/текст) и JSON уроков с ответами | `e-kursi-saturs/` внутри проекта (рабочая копия) | нет (в `.gitignore`) |
| **Резервная копия** | `e-kursi-rezerve/<kurss>.zip.enc`: архив, зашифрованный AES-256 (`node riki/ek-rezerve.mjs`); пароль хранится только у вас (в менеджере паролей) | да: в публичном репозитории лежит только шифр, история версий хранится на GitHub |
| Опубликованный контент | D1, таблица `ek_saturs(kurss, fails, json, versija)` (+ D1 Time Travel: откат до 30 дней) | — |

Без пароля резервная копия бесполезна: и для посторонних, и для нас. Пароль задаётся один раз и нигде в проекте не сохраняется.
Исходные PDF в архив не входят (они большие и уже есть у вас): шифруются только `teksts/`, JSON и планы.

Публикация = скрипт загружает JSON в D1 через `wrangler`. Worker отдаёт уроки только тем, кто оплатил, и не передаёт ответы тестов.

## Шаги

```
e-kursi-saturs/<kurss>/
  avoti/          ← 0. вы кладёте PDF / DOCX / заметки
  teksts/         ← 1. скрипт: сжатый текст по урокам
  plans.json      ← 2. Claude: план курса        → ✋ ваше подтверждение
  nodarbiba-01.json … ← 3. Claude: по одному уроку
  eksamens.json, resursi.json ← 5.
```

| # | Шаг | Кто | Токены | Результат |
|---|---|---|---|---|
| 0 | **Материалы** | вы | — | PDF/DOCX в `avoti/`. Если материалов нет, Claude опирается на открытые источники (§ «Без материалов»). |
| 1 | **Извлечение** `node riki/ek-izvilkt.mjs <kurss>` | скрипт | 0 | `teksts/nodarbiba-N.md`: UTF-8, без повторяющихся заголовков слайдов и пустых строк, плюс список страниц без текста |
| 2 | **План курса** | Claude | ~25 тыс. | `plans.json`: название, уровень, 4–6 навыков, по каждому уроку цели (can-do), ключевые темы и лексика, типы заданий, что добавить сверх исходников (сверка с CEFR / Plan Curricular del Instituto Cervantes). **Стоп: вы утверждаете план** |
| 2a | **Kanons курса** (вместе с планом) | Claude | ~5 тыс. | `kanons.json`: термины и их единственная формулировка, правила (как они сформулированы и в каком уроке введены), лексика по урокам, условности (транскрипция, обозначения). **Это единый источник правды для всех уроков** |
| 3 | **Уроки** | Claude, урок за уроком | ~20–30 тыс./урок | `nodarbiba-NN.json` по схеме: mērķi, затем 3–4 **daļas по ~20 мин** (materiāls + vingrinājumi в каждой), praktiskais uzdevums, банк теста (≈ 1,5× размер теста), kopsavilkums. На входе: план, kanons и **только kopsavilkumi** предыдущих уроков (а не сами уроки). Поле `saites`: на что урок опирается и что готовит |
| 4 | **Проверка** `node riki/ek-parbaudit.mjs <kurss>` | скрипт | 0 | Схема; каждый навык в каждом уроке; у всех заданий есть ответ и пояснение; размер банка; блоки ≤ 250 слов; уникальные `id`; латышские буквы. **Связность**: в заданиях только лексика и правила, введённые в этом или прошлых уроках; термины совпадают с kanons; оценка времени каждой daļa 15–25 мин. Claude правит **только** ошибочные фрагменты |
| 4a | **Проверка противоречий** | Claude | ~8 тыс. | Один проход по kanons и kopsavilkumi всех уроков (без полного текста): нет ли противоречащих формулировок, пропусков и повторов. Исправления вносятся точечно |
| 5 | **Экзамен и ресурсы** | Claude + скрипт | ~20 тыс. | Claude пишет **отдельный банк экзамена** (≈ 1,5× от 40 заданий) по тем же целям, но с **новыми** предложениями, словами-примерами и формулировками; больше заданий, где нужно сочетать несколько уроков. Скрипт проверяет, что **ни одно задание экзамена не совпадает и не похоже** (≥ 70 % по нормализованному тексту или тот же вопрос с тем же ответом) с заданиями тестов самопроверки и упражнений. Найденные совпадения Claude переписывает. `resursi.json`: проверенные открытые ресурсы и пути самообучения после курса |
| 6 | **Предпросмотр** `npx wrangler dev` → `macibas.html?k=<id>&preview` | вы | 0 | Вы проходите курс. Замечания пишете в формате «2. nodarbība, uzd. v-07: …» → точечные правки |
| 7 | **Публикация** `node riki/ek-augsupladet.mjs <kurss> --remote` | скрипт | 0 | JSON → D1; новая строка в `courses` (миграция: цена, срок доступа); карточка в `kursi.html` и страница описания `ek-<id>.html` генерируются из `plans.json`; правка `context.md`; commit + push |

Связность уроков обеспечивают три механизма: kanons (одна формулировка для каждого правила), kopsavilkumi
прошлых уроков на входе каждого нового урока и скрипт, который ловит лексику или правила, использованные раньше, чем они введены.

Повторение пройденного в разминке урока (spaced repetition) скрипт берёт из банков предыдущих уроков: на это не тратятся токены и это не требует ручной работы.

## Без материалов

Claude строит план по открытым и надёжным источникам и указывает их в `plans.json → avoti`:
- описание уровней CEFR (Совет Европы),
- для испанского: Plan Curricular del Instituto Cervantes (inventarios A1–B2),
- для английского: English Profile / British Council LearnEnglish,
- открытые учебники (OER, например OpenStax / LibreTexts по теме курса).

Тексты не копируются, а пишутся заново. В плане каждое утверждение помечается источником, чтобы его было легко проверить.

## Решения владельца (2026-11-11)

1. Приватного репозитория нет → рабочая копия хранится локально, на GitHub лежит зашифрованная резервная копия, опубликованный контент хранится в D1.
2. Интерфейс и объяснения на латышском, примеры на изучаемом языке.
3. Урок делится на **daļas по ~20 мин** (3–4 на урок); прогресс сохраняется по daļām, и «Turpināt» ведёт к первой незавершённой.
4. Уроки логически связаны и не противоречат друг другу (kanons + шаги 4 и 4a).
5. Экзамен не повторяет задания тестов самопроверки (отдельный банк + проверка скриптом, шаг 5).
