# E-kursi (pašmācības kursi) — структура · этап 1 из 3

Статус: **на согласовании**. После «да» → этап 2 (визуал), затем этап 3 (пайплайн), затем скилл.

Рабочее название услуги на сайте: **«Tiešsaistes kursi — mācies savā tempā»** (в коде префикс `ek-` / id `ek-…`).
Отличие от групповых курсов: нет группы и расписания, нет аккредитации самоуправлением, покупается **доступ к цифровому учебному контенту**.

---

## 1. Состав одного курса (единый шаблон для всех)

```
Kursa sākums (обзор)
├─ 0. Ievads: kā mācīties šajā kursā      ← один раз, не оценивается
├─ 1…N. Nodarbība (обычно 6–10)           ← каждая по одному шаблону (см. §2)
│     └─ Pašpārbaudes tests ≥ 80 %  → открывает следующую
├─ Noslēguma eksāmens  ≥ 80 %             ← открывается, когда все N тестов сданы
├─ Sertifikāts                            ← выдаётся автоматически после экзамена
└─ Ko darīt tālāk: resursi un ceļi        ← последний раздел, открыт всегда после экзамена
```

**Карта навыков курса** (задаётся в начале каждого курса): 4–6 навыков, которые курс развивает
(для языкового: *vārdu krājums, gramatika, lasīšana, klausīšanās, rakstīšana, runāšana*).
Каждое задание помечено навыком → в конце видно, что тренировалось, и шаблон проверяет,
что **каждый навык тренируется в каждом уроке** и проверяется на экзамене.

## 2. Шаблон урока (методика самообучения)

Основа — цикл *активировать → объяснить → потренировать → проверить → осмыслить*
(Gagné / retrieval practice / spaced repetition). Порядок фиксирован. Урок ≈ 60–90 мин и делится на
**3–4 daļas по ~20 мин**: блоки 3–4 (materiāls + vingrinājumi) повторяются в каждой daļa, прогресс сохраняется по daļām.
Уроки опираются друг на друга и не противоречат (единый `kanons.json`, см. pipeline.md).

| № | Блок | Что внутри | Оценка |
|---|---|---|---|
| 1 | **Mērķi** | «Pēc šīs nodarbības tu varēsi…» 3–4 can-do пункта, время, навыки урока | — |
| 2 | **Iesildīšanās** | 1–2 вопроса «что ты уже знаешь» + **повтор 2–3 заданий из прошлых уроков** (spaced repetition) | нет |
| 3 | **Mācību materiāls** | Короткие блоки (≤ 250 слов): объяснение, таблица, примеры, аудио (TTS), карточки слов, рамка «Svarīgi!» | — |
| 4 | **Vingrinājumi** | 6–12 заданий, мгновенная обратная связь + пояснение, без лимита попыток | нет |
| 5 | **Praktiskais uzdevums** | Продуктивный навык: написать / сказать (запись голоса) / применить. Самопроверка по образцу и чек-листу | нет |
| 6 | **Pašpārbaudes tests** | 10–15 вопросов, только автопроверяемые типы, **≥ 80 %** → следующий урок | **да** |
| 7 | **Kopsavilkums** | 5 главных мыслей + самооценка can-do (😀/🙂/😐) + «Mana piezīme» (личная заметка) | нет |

**Правила теста урока**
- Попытки не ограничены; вопросы и варианты перемешиваются; при пересдаче берётся другой набор из банка (банк ≈ 1,5× размер теста).
- После попытки: балл + какие ответы неверны + ссылка «Atkārto: <блок материала>». Правильные ответы показываются только после сдачи (иначе тест учится наизусть).
- Засчитывается лучший результат.

**Финальный экзамен**
- 30–50 заданий из всех уроков, все типы автопроверки, пропорционально навыкам; таймера нет (можно включить на курс).
- ≥ 80 % → сертификат. Не сдал → разбор по урокам («слабые места: 3. un 5. nodarbība») и повтор через **24 ч** (чтобы человек повторил, а не перебирал).

## 3. Типы заданий (каталог — общий для всех курсов)

Автопроверяемые (тесты, экзамен, упражнения):
`izvele` (один ответ) · `vairakas` (несколько) · `ievadi` (вписать, допустимые варианты через `|`) ·
`tuksumi` (пропуски в тексте) · `pari` (соединить пары) · `seciba` (упорядочить) ·
`klausies` (аудио → выбор/ввод) · `teksts` (прочитать текст → вопросы) · `kategorijas` (разложить по группам)

Самопроверка (только упражнения/практика, в баллы не идут):
`rakstit` (свободный текст + образец + чек-лист) · `runat` (запись голоса через микрофон, прослушать и сравнить с образцом)

## 5. Техническая схема (коротко)

- **Контент курса = данные, не HTML**: `e-kursi/<id>/kurss.json` (+ `nodarbiba-01.json`…). Один рендерер → все курсы одинаковые, генерация дешёвая по токенам.
- Контент **не публикуется как статика** (в `.assetsignore`), его отдаёт Worker **только оплатившим**: `GET /api/ek/<id>/nodarbiba/<n>` — без правильных ответов.
- **Проверка тестов на сервере**: `POST /api/ek/<id>/tests/<n>` → балл, открытие следующего урока. Нельзя «подсмотреть» ответы или открыть урок через DevTools.
- Упражнения (не тесты) проверяются в браузере — там ответы можно отдавать.
- Новые таблицы D1: `ek_progress` (user, kurss, nodarbība, labākais %, nokārtots_at, piezīme, pašvērtējums), `ek_meginajumi` (попытки), `ek_sertifikati` (kods, user, kurss, vārds uzvārds, datums, %).
- Курс в `courses` + колонка `veids` (`grupa` / `ekurss`); покупка — через существующий `enrollments` (статус: *Gaida apmaksu → Aktīvs → Pabeigts*). Оплату пока отмечает админ, как сейчас.

## 6. Сертификат

- Поля подставляются автоматически: **Vārds Uzvārds**, **kursa nosaukums**, **pabeigšanas datums**, plus кол-во часов (по курсу), результат экзамена, уникальный код `LIB-EK-2026-XXXXXX` и QR/ссылка на проверку.
- Перед выдачей клиент один раз подтверждает «Vārds un uzvārds sertifikātam» (имя из Google часто неполное/латиницей) → после выдачи не меняется (через админа).
- Текст внизу: «Apliecina digitālā mācību satura apguvi. Nav valsts atzīts izglītības dokuments.»
- Сразу появляется в «Mani kursi» + письмо «Apsveicam!» (Resend уже подключён).

## 7. Юридическая часть (noteikumi.html + чекбокс при покупке)

- Клиент покупает **piekļuvi digitālajam mācību saturam**, а не uzņemšanu izglītības programmā; курс не является аккредитованной/лицензированной программой неформального образования, сертификат — не документ об образовании.
- Право отказа 14 дней: для цифрового контента теряется, если клиент **явно согласился** начать сразу и подтвердил, что теряет право отказа → отдельный обязательный чекбокс при покупке + подтверждение в письме. (Формулировки проверить юристу — MK noteikumi Nr. 255 «Noteikumi par distances līgumu».)
- Срок доступа, личное использование, запрет передачи аккаунта, авторские права на материалы.

## 8. Решения владельца (2026-11-11)

1. **Срок доступа**: по умолчанию **3 месяца** с момента активации (отметка оплаты). Владелец меняет срок
   курса по умолчанию и срок конкретного участника (продлить / сократить) в настройках курса.
2. **Экзамен**: пересдача через 24 ч, **максимум 3 попытки**. После 3 неудачных клиент выбирает:
   - **A) Konsultācija ar pasniedzēju** (платно, цена = цена консультации) → +3 попытки;
   - **B) Apmaksāt papildu mēģinājumus** (сумма = цена консультации, без консультации) → +3 попытки.
   Правило видно: на странице описания курса, в карточке «Kā notiek», на экране экзамена до старта
   («Mēģinājums 1 no 3») и в Noteikumi. Цена консультации редактируется владельцем.
3. **Цена курса**: 140 EUR, редактируется владельцем (настройки курса → `courses.price_eur`).
4. **Пилот**: «Spāņu valoda A1 — pirmie soļi» из 5 презентаций SVA1: 1) alfabēts, izruna, uzsvars;
   2) lietvārdi: dzimte, daudzskaitlis; 3) artikuli; 4) vietniekvārdi; 5) iepazīšanās, pieklājības frāzes.

## 9. Настройки курса (только для владельца, `admin.html` → вкладка «E-kursi»)

- Kurss: cena, piekļuves ilgums (dienas, default 90), konsultācijas / papildu mēģinājumu cena, aktīvs/slēpts.
- **Dalībnieki**: vārds, e-pasts, apmaksāts, *piekļuve līdz* (дата, можно изменить), progress (3/5 nodarbības),
  eksāmena mēģinājumi (2/3, кнопка «+3 mēģinājumi» после оплаты), sertifikāts (kods / nav).
- Сортировка «скоро истекает», бейдж «Beidzas 7 dienās». Клиенту за 7 дней — письмо-напоминание.

Таблица `ek_pieklujes` хранит по участнику: `aktivizets_at`, `lidz` (дата окончания), `eksamena_limits` (3, +3 …).
